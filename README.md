# CodePath — Путь начинающего программиста

## 🎯 О проекте

**CodePath** — это образовательная платформа для начинающих программистов, где можно найти свой язык программирования, изучить основы кодирования и просмотреть реальные проекты с открытым исходным кодом.

Платформа охватывает:
- Языки программирования (Python, JavaScript, Java, C++, Go, Rust и др.)
- Веб-технологии (HTML, CSS, JavaScript)
- Практические проекты с пошаговыми объяснениями
- Связанные темы и перекрёстные ссылки для глубокого понимания

## 📄 Шаблон страницы темы

Каждая страница темы следует единой структуре:

```
1. Заголовок темы
2. Краткое введение (2-3 предложения)
3. Теоретическая часть
   - Объяснение концепции
   - Ключевые понятия
   - Важные нюансы
4. Примеры кода
   - Базовый пример
   - Продвинутый пример
   - Комментарии к коду
5. Применение на практике
   - Реальные кейсы
   - Где используется
   - Преимущества и ограничения
6. Связанные темы
   - Ссылки на предыдущие темы (предварительные знания)
   - Ссылки на следующие темы (куда двигаться дальше)
   - Ссылки на смежные концепции
7. Часто задаваемые вопросы по теме
   - 3-5 вопросов с ответами
   - Ссылки на связанные разделы при необходимости
8. Навигационные элементы
   - "Назад" / "Вперёд"
   - "К оглавлению раздела"
   - "К главному меню"
```

## 🎨 Дизайн и интерфейс

### Принципы дизайна

- **Минимализм**: чистый интерфейс без визуального шума
- **Читаемость**: приоритет контенту, удобные шрифты
- **Навигация**: интуитивно понятная структура переходов
- **Доступность**: контрастные цвета, семантическая вёрстка
- **Адаптивность**: корректное отображение на всех устройствах

### Цветовая палитра

```
Основной фон: #FFFFFF (белый) или #1A1A2E (тёмная тема)
Текст: #2D3436 (светлая) / #EAEAEA (тёмная)
Акценты: #0984E3 (синий), #00B894 (зелёный)
```

## 🔗 Система связей между темами

### Типы связей

1. **Предварительные знания** (Prerequisites)
   - Что нужно знать перед изучением темы
   - Пример: перед "Функциями" → "Переменные", "Типы данных"

2. **Продолжение** (Next Steps)
   - Куда двигаться после изучения темы
   - Пример: после "Основ HTML" → "CSS для стилизации"

3. **Смежные темы** (Related)
   - Параллельные концепции для углубления
   - Пример: "Flexbox" ↔ "Grid Layout"

4. **Проекты по теме** (Projects)
   - Практическое применение знаний
   - Пример: после "Основ JavaScript" → проект "Калькулятор"

5. **Частые вопросы** (FAQ Links)
   - Ответы на вопросы в других разделах
   - Пример: вопрос про асинхронность → ссылка на раздел "Promise"

### Визуализация связей

На каждой странице:
- Блок "Перед началом изучите:" (сверху)
- Блок "Далее рекомендуется:" (снизу)
- Боковая панель с навигацией по разделу
- Хлебные крошки для ориентации

### Структура файлов

    ├── images/

### Технологии

- **HTML5**: семантическая вёрстка
- **CSS3**: Flexbox, Grid, CSS Variables
- **JavaScript (Vanilla)**: навигация, поиск, переключение темы
- **Prism.js**: подсветка синтаксиса кода
- **Нет фреймворков**: максимальная простота и скорость

### Требования к производительности

- Загрузка страницы < 2 секунд
- Lighthouse score > 90
- Поддержка старых браузеров (ES6+)
- Оптимизированные изображения (WebP + fallback)

## 🤝 Вклад в проект

### Как добавить новую тему

1. Создать папку в соответствующем разделе
2. Использовать шаблон страницы
3. Добавить перекрёстные ссылки
4. Протестировать навигацию
5. Отправить на проверку

### Как добавить проект

1. Создать папку в `/projects/[уровень]/[название]`
2. Добавить `README.md` с описанием
3. Предоставить полный исходный код
4. Написать пошаговое руководство
5. Связать с необходимыми темами
